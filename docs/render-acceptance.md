Pixel fractions are measured after rendering, before publication, and recorded in the manifest; thresholds remain in expected findings so antialiasing variation does not require rewriting a pixel-count baseline.

## Deviations

- The pinned data-centre source has two `proxyClassified` health warnings on utility intake elements. The core row reports both and compares their complete findings with the untouched source; no warning is filtered or regraded. Derived outputs introduce no errors or warnings. This also prevents source warnings from hiding a new finding.

- Toolchain is pinned to v0.3.0 instead of retaining v0.2.1, whose raw S09/S10 failures are documented in the [previous release](migration.md). The available release includes the fixes; no local lint waiver is used.
- The available data-centre and IFC siblings had advanced to v0.4.2 and v0.1.1. Final checks use separate extractions of the pinned v0.4.1 and v0.1.0 tags; no sibling checkout is changed and source mode remains pinned.
- Privacy shells are written but hidden in the overview because its outdoor views dominate the composition. The eleven CriticalDoors shells are the displayed study geometry. Nominal sectors stay visible for any sensor without a shell.
- The area is a scanline estimate of XY projection clipped to hall footprints, with refinement reported; it is not an exact continuous-visibility calculation.
- Unlit Embree ignores opacity. The presentation hides nominal sectors with shells and uses bounded display colours and a 100% camera light; study output keeps its original opacity.
- One `nix flake check` attempt exited 1 before evaluation: Nix rejected the temporary data-centre source override because an ancestor directory is a symlink. The attempt used offline mode, local source overrides, no substituters or remote builders and zero build jobs. Nix build/check results are **not proven**; no retry or installation was made.

The five pytest skips are one optional sync binding, three opt-in facility performance cases and one unavailable native-export fixture. None is counted as a pass. The opt-in real-data and live integration gates are not run. No private input is read and no external application is changed.

Final gate execution repeats the image measurements from newly rendered PNGs: overview foreground 23.66%, 165,582 bytes; look-through foreground 98.55%, 240,016 bytes; both have 0% saturated white. The table above names the committed render artifacts; minor antialiasing variation changes PNG hashes and bytes without changing the acceptance limits. The regenerated images retain the same cameras, geometry, presentation and study findings.
